# Antigravity AI OS: System Workflow

The system operates as a tiered multi-agent architecture integrated with an Model Context Protocol (MCP) backbone.

## 1. Request Lifecycle
1. **User Input**: Task is received via the `AIChat` or `App` interface.
2. **Orchestrator (Async)**: Initialized the task, setting the "running" state.
3. **Planner Agent**:
   - Analyzes project context.
   - Decomposes goal into a JSON-serialized instruction set.
4. **Coder Agent**:
   - Loops through instructions.
   - Routes tool calls (mkdir, create_file, etc.) through the **Skill Router**.
   - Skill Router identifies the target **MCP Server** (Local/Remote).
5. **Reviewer Agent**:
   - Audits the resulting filesystem changes and code quality.
   - Issues "APPROVED" or "REJECTED" (triggers retry loop).

## 2. Infrastructure Layer
- **MCP Server**: Fast API-based toolkit for filesystem and OS operations.
- **Port Monitor**: Background thread detecting hardware changes and emitting events.
- **Event Bus**: Decoupled communication for hardware alerts and UI updates.

## 3. Visualization Flow
- **Editor**: Real-time code manipulation.
- **Preview Canvas**: Renders HTML/JS assets generated by the agent.
- **Terminal**: Real-time log monitoring of active Python processes.
